# Legal notice and project rules

Kirikae is a recompiler: it reads a Nintendo Switch executable you already have and produces an
equivalent program for the PC. The project exists for preservation, for study, and to play on the PC
the games you bought. This document says what Kirikae is, what it is not, and the rules for users and
contributors.

*This is not legal advice. Laws differ from country to country; when in doubt, ask a lawyer.*

## What the repository contains

- Original code, under MIT or Apache-2.0 ([LICENSE-MIT](LICENSE-MIT), [LICENSE-APACHE](LICENSE-APACHE)).
- No games, firmware, keys, BIOS, system fonts, SDKs, shaders or artwork from Nintendo or anyone else.
  The tests use synthetic programs generated by Kirikae itself.
- No decryption code: Kirikae only reads dumps that are already decrypted.
- No executable generated from a game.

## Rules for users

1. **Only use games from your own console.** Dump the game on your own Switch. Files downloaded from
   the internet, even of a game you bought, are not your dump.
2. **Do not distribute what Kirikae generates.** The recompiled `.exe` contains the game's translated
   code, and so do its debug symbols (`.pdb`), profile (`.profile`), saves and captures. All of that
   stays on your machine.
3. **Do not ask for or offer games, keys or firmware** in issues, pull requests or any project channel.
   Such requests are closed without an answer.

## Rules for contributors

1. **Clean-room reverse engineering.** Accepted references are public documentation and code under a
   compatible license: [Switchbrew](https://switchbrew.org), Ryujinx (MIT), envytools (MIT), NVIDIA's
   open GPU documentation (open-gpu-doc, MIT), the Arm Architecture Reference Manual and the Vulkan
   specifications. Anything taken from MIT/BSD projects keeps its original copyright notice.
2. **No GPL code** (yuzu, suyu, ScarletNX and derivatives): it would force the whole project to become GPL.
3. **No leaked or NDA material**: Nintendo's SDK, developer documentation, game source code.
4. **No game data in tests or documentation**: no binaries, extracted shaders, textures, screenshots
   or memory dumps. Describing observed behavior (a register, a structure field, the order of an
   initialization) is fine; copying the content is not.
5. **No links** to ROM, key or firmware sites, anywhere in the repository.

## Third-party material

- [`tools/reference/horizon.txt`](tools/reference/horizon.txt): IPC command, SVC and ioctl numbers and
  names documented on [Switchbrew](https://switchbrew.org), under CC BY-SA. That file follows
  Switchbrew's license, not Kirikae's, and is only used by the progress tool.
- [`crates/maxwell/src/opcodes.rs`](crates/maxwell/src/opcodes.rs): opcode table generated from
  envytools' `envydis/gm107.c` (MIT); the original notice is at the top of the file.
- [`crates/rt/src/nvn/resources.rs`](crates/rt/src/nvn/resources.rs): the block sizes per NVN texture
  format follow Savage Wind Recomp's table (MIT, Copyright (c) 2026 Revivedx and the Savage Wind Recomp
  contributors; Copyright (c) 2026 Peiikai).
- Cargo dependencies: all under permissive licenses (MIT, Apache-2.0, BSD, Zlib, ISC, Unlicense). The
  H.264 decoder uses Cisco's OpenH264 built from source (BSD-2). The H.264 patent license Cisco offers
  only covers binaries distributed by Cisco itself, not an OpenH264 you build; anyone distributing
  Kirikae binaries should keep that in mind.
